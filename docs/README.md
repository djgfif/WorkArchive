# docs/

Work Archive 문서를 주제별로 정리하기 위한 문서 루트입니다.

## 폴더 구조
- `docs/project/` : 프로젝트 개요, 현재 상태, 초기 구현 계획
- `docs/product/` : 제품 방향, 최종 웹디자인, 상용화 디자인 계획
- `docs/frontend/` : 프론트엔드 설계도, 프론트 구조 마스터플랜
- `docs/backend/` : 백엔드 재설계 마스터플랜
- `docs/management/` : 문서 인덱스, 거버넌스, 상태표, 정합성 보고서

## 현재 운영 원칙
지금 단계에서는 **안전한 정리**를 우선합니다.

- 우선 `docs/` 아래에 분류 체계를 만든다.
- 문서 기준/우선순위/분류를 `docs/management/`에 정리한다.
- 이후 실제 파일 이동은 참조 경로와 중복 정리를 확인하면서 진행한다.

## 먼저 볼 문서

- 문서 인덱스: `../DOCUMENTATION_INDEX.md`
- 문서 운영 규칙: `../DOCUMENTATION_GOVERNANCE.md`
- 문서 상태표: `../DOCUMENT_STATUS_MATRIX.md`
- 코드-문서 정합성: `../CODE_DOCUMENT_ALIGNMENT_REPORT.md`

## 장기 목표
장기적으로는 루트에 흩어진 문서를 단계적으로 `docs/` 하위 폴더로 이동하고,
루트에는 `README.md`와 개발 실행에 직접 필요한 파일만 남기는 것을 목표로 합니다.
