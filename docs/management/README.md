# docs/management/

문서 체계 자체를 관리하는 영역입니다. 읽는 순서, 상태 분류, 거버넌스, 코드-문서 정합성 해석 규칙을 이 폴더에서 통제합니다.

## 포함 대상
- [`DOCUMENTATION_INDEX.md`](./DOCUMENTATION_INDEX.md)
- [`DOCUMENT_STATUS_MATRIX.md`](./DOCUMENT_STATUS_MATRIX.md)
- [`DOCUMENTATION_GOVERNANCE.md`](./DOCUMENTATION_GOVERNANCE.md)
- [`CODE_DOCUMENT_ALIGNMENT_REPORT.md`](./CODE_DOCUMENT_ALIGNMENT_REPORT.md)

## 역할
- 저장소 문서의 공식 탐색 진입점 제공
- canonical / active / reference / archived 상태 관리
- 현재 코드 현실 문서와 미래 비전 문서를 구분하는 기준 제공
