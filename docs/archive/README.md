# Archive

This folder keeps historical material out of the active documentation path
without deleting context.

## Contents

- [`backend/`](./backend/): backend redesign plans and completed hardening notes.
- [`design/`](./design/): design contract snapshots, imported visual references,
  and raw Stitch outputs.
- [`frontend/`](./frontend/): frontend audits, roadmaps, and completion reports.
- [`management/`](./management/): old alignment reports and execution prompts.
- [`product/`](./product/): product strategy, UI system, and expansion plans.
- [`project/`](./project/): early project specs and implementation plans.
- [`qa/`](./qa/): focused QA notes.
- [`testing/`](./testing/): historical testing plans.

## Rule

Archived documents are reference material. If an archived document becomes
current again, move it into the appropriate active area and update
[`../README.md`](../README.md) plus
[`../management/DOCUMENTATION_INDEX.md`](../management/DOCUMENTATION_INDEX.md).
