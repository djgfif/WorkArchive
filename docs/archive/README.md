# docs/archive/

아직 기준 문서가 아니고, 역사 보존을 위해 별도 격리할 가치가 생긴 문서를 보관하는 영역입니다.

## 목적
- 현재 기준 문서와 과거 문서를 물리적으로 분리
- 삭제 없이 역사적 맥락 보존
- future vision 문서와 obsolete 문서를 혼동하지 않도록 정리

## 현재 운영 상태
- 이번 구조 정리 패스에서는 archive를 먼저 만들기만 하고, 문서를 성급하게 이동하지 않습니다.
- reference 문서라도 현재 맥락 이해에 계속 유용하면 당분간 원래 주제 폴더에 둡니다.

## 이동 기준
- 현재 구현/설계와 강하게 충돌해 더 이상 기준처럼 읽히면 archive 후보입니다.
- 대체 문서가 명확하고 재참조 빈도가 낮으면 archive 후보입니다.
- archive로 이동할 때는 [`../management/DOCUMENTATION_INDEX.md`](../management/DOCUMENTATION_INDEX.md)와 [`../management/DOCUMENT_STATUS_MATRIX.md`](../management/DOCUMENT_STATUS_MATRIX.md)를 함께 갱신합니다.
