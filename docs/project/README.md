# docs/project/

프로젝트의 기본 맥락과 현재 상태를 다루는 문서 모음입니다.

## 포함 대상
- `CURRENT_STATUS_AND_FUTURE_PLAN_REPORT.md`
- `PROJECT_SPEC.md`
- `IMPLEMENTATION_PLAN.md`
- `PLAN.md`
- `IMPLEMENT.md`

## 역할
- 현재 상태 보고
- 초기 요구사항과 milestone 기록 보존
- 과거 계획과 현재 기준의 차이 비교

## 읽는 순서
1. `../../CURRENT_STATUS_AND_FUTURE_PLAN_REPORT.md`
2. 필요 시 `../../PROJECT_SPEC.md`
3. 필요 시 `../../IMPLEMENTATION_PLAN.md`
4. 과거 milestone 맥락이 필요하면 `../../PLAN.md`, `../../IMPLEMENT.md`
