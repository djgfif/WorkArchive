# docs/project/

프로젝트의 현재 상태, 전체 맥락, 과거 계획 문서를 보관하는 영역입니다. 아직 archive로 내리기 이른 역사 문서도 이 폴더에서 함께 관리합니다.

## 포함 대상
- [`CURRENT_STATUS_AND_FUTURE_PLAN_REPORT.md`](./CURRENT_STATUS_AND_FUTURE_PLAN_REPORT.md)
- [`PROJECT_SPEC.md`](./PROJECT_SPEC.md)
- [`IMPLEMENTATION_PLAN.md`](./IMPLEMENTATION_PLAN.md)
- [`PLAN.md`](./PLAN.md)
- [`IMPLEMENT.md`](./IMPLEMENT.md)

## 역할
- 현재 코드 현실과 가까운 상태 보고 제공
- 초기 요구사항, milestone, 구현 지시 문맥 보존
- 현재 기준 문서와 과거 계획 문서의 차이 비교 지원

## 읽는 순서
1. [`CURRENT_STATUS_AND_FUTURE_PLAN_REPORT.md`](./CURRENT_STATUS_AND_FUTURE_PLAN_REPORT.md)
2. 필요 시 [`PROJECT_SPEC.md`](./PROJECT_SPEC.md)
3. 필요 시 [`IMPLEMENTATION_PLAN.md`](./IMPLEMENTATION_PLAN.md)
4. 과거 milestone 맥락이 필요하면 [`PLAN.md`](./PLAN.md), [`IMPLEMENT.md`](./IMPLEMENT.md)

## Source Of Truth 메모
- 현재 프로젝트 상태의 기준 문서는 [`CURRENT_STATUS_AND_FUTURE_PLAN_REPORT.md`](./CURRENT_STATUS_AND_FUTURE_PLAN_REPORT.md)입니다.
- [`PROJECT_SPEC.md`](./PROJECT_SPEC.md), [`IMPLEMENTATION_PLAN.md`](./IMPLEMENTATION_PLAN.md), [`PLAN.md`](./PLAN.md), [`IMPLEMENT.md`](./IMPLEMENT.md)는 reference 문서입니다.
- 이 폴더의 reference 문서는 의미를 잃지 않았으므로 이번 패스에서는 archive로 이동하지 않습니다.
